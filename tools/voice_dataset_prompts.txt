# Prompt list for generate_voice_dataset.py
#
# 153 lines total. At a typical 3.5-4.5s per clip this yields roughly 9-11
# minutes of audio, which is the target for a first usable Piper fine-tune.
# Run --stats after generating to see where you actually landed.
#
# One utterance per line. Blank lines and lines starting with # are ignored.
# Filenames come from a hash of the text, so you can reorder, insert and
# delete lines freely without invalidating clips you've already paid for.
#
# Two halves, doing two different jobs:
#
#   PART 1 (78 lines) - in character. Teaches delivery, energy, and the
#   question and exclamation intonation the model would otherwise never
#   learn.
#
#   PART 2 (75 lines) - phonetic coverage. Deliberately plain sentences
#   spread across English consonants, vowels, diphthongs and clusters, so
#   the model doesn't mispronounce sounds that never appeared in Part 1.
#   These read boring. That is exactly what they are for. Don't cut them.
#
# If --stats says you're short of 10 minutes, add more Part 1 style lines
# rather than more Part 2 - you'll already have the phonetic coverage, and
# extra in-character material is what improves how it actually sounds.
